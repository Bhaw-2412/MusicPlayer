# 🎵 Music Player App (React Native + JioSaavn API)

A music streaming mobile application built using **React Native** that allows users to search, browse, and play songs using the **JioSaavn public API**.  
This project is created as a **learning / internship assignment** focusing on clean UI, proper architecture, and smooth audio playback.

---

## 📱 Features

- 🎶 Browse popular songs
- 🔍 Search songs, albums, and artists
- ▶️ Play / Pause music
- ⏭️ Next / Previous track
- 🖼️ Song artwork and artist details
- 🎧 Mini player & full player screen
- 📱 Android & iOS support

---

## 🛠️ Tech Stack

- React Native
- Expo
- JavaScript
- JioSaavn API
- Axios
- React Navigation
- Expo AV (Audio)
